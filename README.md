# Задание

Лабораторная работа № 9. Изучить Room и DataStore. Создать приложение Tasks для работы с задачами на выбранную дату. У каждой задачи есть название, время и описание.

# Выполнено

Приложение на Kotlin и Jetpack Compose показывает задачи за выбранный день. Даты можно листать от сегодняшней или выбирать в календаре. Задачи можно создавать, открывать, редактировать и удалять. Список сортируется от ранних задач к поздним, в обратном порядке или по алфавиту.

Задачи хранятся в Room. DataStore запоминает последнюю выбранную дату и сортировку. Его экземпляр передаётся в `SettingsRepository` через конструктор.

Для запуска откройте проект в Android Studio и запустите модуль `app`.
